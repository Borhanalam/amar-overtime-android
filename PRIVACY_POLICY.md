# Privacy Policy — আমার ওভার টাইম

**Developer:** BORHAN  
**App:** আমার ওভার টাইম

## Data storage
The app is designed to work offline. Worker names, salary settings and duty records are stored locally on the user's device using the app's local storage.

## Data sharing
The app does not include an online account or server/database in this version. Data is not automatically uploaded to the developer.

## Backup and export
If the user chooses Backup, Restore or CSV Export, the user controls where the exported file is saved and how it is shared. The developer does not receive those files automatically.
